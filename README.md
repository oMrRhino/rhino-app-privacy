# Rhino App Development — app privacy policies

One public privacy-policy page for Rhino App Development Android apps, starting with Workshop Pal.

## Publish with GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, select main and / (root), and save. The page is plain HTML and CSS. The .nojekyll file disables Jekyll processing. No build dependencies or paid domain are required.

## Future apps

Add a clearly labelled policy article with a unique stable ID and a navigation link to index.html. Describe the actual behaviour of that app. Preserve existing app policy sections and anchors. Update the affected policy date when its handling of information changes.
